# 重传数据链路层

重传数据链路层的统称为包

## 功能

因为需要使用UDP收发，需要将完整长帧拆分到每包1400字节以下。

还需要在这一层实现重传协议

## 包格式


|  | **长度\(Byte\)** | **说明** |
| --- | --- | --- |
| 包头 | 2 | 固定0xABAB |
| 设备类型 | 2 | 目标设备 |
| 整帧序号 | 2 | 和对应的帧id相同 |
| 总包数 | 2 | 通常为1，拆n包则为n。 |
| 当前包编号 | 2 | 通常为1，拆n包则为1\~n。 |
| 重传说明 | 4 | 0代表发送方的包
1代表接收方接收有问题，需要发送方重传，数据中放需要重传的包标号 |
| 空 | 4 | 空 |
| 数据长度 | 2 | 当前Data长度\(Byte\) |
| Data | n | 数据整个协议帧 |
| CRC16 | 2 | CRC\-16/MODBUS

Polynomial: x^16 \+ x^15 \+ x^2 \+ 1

（除帧头、帧尾和校验字段后的全部数据） |
| 帧尾 | 2 | 固定0xDCDC |
